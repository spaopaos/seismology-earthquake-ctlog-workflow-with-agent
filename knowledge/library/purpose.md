# Project Purpose

## Goal

Maintain an English, source-grounded knowledge base for earthquake catalog construction and the design of scientific agents. Make the local papers and manuals easy to navigate, compare, and use without losing their assumptions or version context.

## Key questions

1. How do phase picking, association, absolute location, relative relocation, and matched filtering connect?
2. What evidence and quality checks are appropriate at each stage?
3. How do AutoBA, the Mindat workflow, and the SPECFEM MCP suite organize scientific tool use?
4. Which design lessons can reasonably transfer to a seismology agent, and which still require experiments?
5. Which software-version and evidence gaps prevent a stronger operational claim?

## Scope

The initial corpus contains eight local documents, totaling 239 PDF pages. It includes five seismic processing references and three scientific-agent papers. Preserve their original evidence and bibliographic details. Related methods mentioned in a paper are not independent primary sources unless separately imported.

This knowledge base does not claim that a combined seismic pipeline has been executed or that agent experiments have been reproduced. It does not infer undocumented runtime parameters from a paper's example settings.

## Working thesis

Scientific agents can make established tools more accessible when their interfaces, execution outcomes, and provenance remain inspectable. Trustworthy scientific output additionally requires validation appropriate to the underlying method. This is a synthesis to investigate, not a new empirical result.
