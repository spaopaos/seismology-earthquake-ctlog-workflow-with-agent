# SPECFEM MCP Server Suite

The suite exposes SPECFEM2D, SPECFEM3D Cartesian, and SPECFEM3D Globe operations as agent-invocable tools. The preprint demonstrates Cline orchestrating configuration, meshing, simulation, and output handling.

The scientific solver remains SPECFEM. The contribution is a tool and workflow interface around existing numerical executables ([ren-2025-seismology-modeling-agent](../sources/ren-2025-seismology-modeling-agent.md), PDF p. 8).

Five forward-modeling cases demonstrate operational use. Autonomous hypothesis generation, iterative inversion, and broader discovery are outlook directions rather than established outcomes of those cases (PDF pp. 22, 24).
