- 任务书口径"跨源 ≤2 s"在 v2 目录上实际命中 **1,201** 个 mess 事件

  其中距离 >1 km 的 230+ 个显然不是同一事件。"随机巧合 ~1–2 对"的预期
  低估了爆发簇聚（均匀背景模型不适用）。

  （origin_time 截断到厘秒 = event.dat/hypoDD 的 HHMMSSCC 约定）。
- 但厘秒 bin 会漏掉跨 bin 的同采样对：**75 个 mess 事件与模板时刻差
  0.2–11 ms**（如 mess0000507↔gm000224 差 0.4 ms），是同一物理事件的
  重复宣告，只是落在 bin 边界两侧。只剔 627 会在终版目录残留 **71 对
  "同一瞬间"重复行**（T1 实测，见 run1 存档 `output_run1_csbin627/`）。
- **v3 采用口径：|Δt| ≤ 0.011 s（100 Hz 原生采样的 1 个采样 + 容差），
  跨源最近对 = 702 个孪生 mess 行（confirmed 401 + ambiguous 301）**。
  处置动作与任务书一致（剔除 + dt.cc 转挂），仅清单比 628 口径多 75 个
  同采样对。对照计数（不重解）见 T6。

## T4 定位质量与保留率

- 保留率：4,630/4,682 = **98.89%**（≥98% 通过）。hypoDD 解出 4,677；
  52 个 v2 存活事件未解出（含 gm001641 与 51 个孤立/低连接事件），
  按补回约定保留 v2 坐标，清单在 `results.json:T4.kept_v2_coords`。
- 事件级 CT 残差 rms（rmsn，= v2 目录 rms 列同源）中位：
  v2 0.068 → v3 0.076（共同事件 3,961 个：差 2,989 / 优 556）。
- 事件级 CC 残差 rms（rmsc）中位：v2 0.023 → v3 0.028
  （共同 3,153 个：差 2,485 / 优 396）。
- **名义判定：不劣化不通过（中位 +8 ms CT / +4 ms CC）。机理（非数据
  质量劣化）**：(i) v2 里 702 个幻影行各带 4 个自由参数，吸收了自身
  观测的失配；剔除后失配回到真实事件名下；(ii) rms 上升在"未获转挂
  边"的事件上同样出现（0.024→0.028），说明是全局重解的重分布效应，
  而非转挂观测本身污染（否则 CC rms 会到 0.1 s 量级）。绝对量级
  （CT p50 76 ms、CC p50 28 ms）仍在差分定位正常范围。

## 结论

终版目录 v3 可交付：重复宣告清零（T1）、保留率 98.9%（T4）、哑火模板
全部拿回 CC 约束（T5）、主震位置在重解噪声带内（T3）。名义上 T4 的
rms"不劣化"不通过（中位 +8 ms CT / +4 ms CC），机理是幻影自由参数
消失后的失配重归属 + 全局重解，属诚实化代价而非质量劣化。
与任务书预期的偏差全部集中在孪生口径（702 vs 628）：处置动作、参数、
流程与任务书一致；口径差异的证据链见第 0 节与 `scripts/dbg_calib/`。
