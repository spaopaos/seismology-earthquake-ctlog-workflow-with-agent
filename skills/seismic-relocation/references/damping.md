# 阻尼证据规则 v1.7

本文件是 DAMP 选值和 CND 使用的当前规范。agent 在既有授权范围内完成少量试算、记录证据并采用支持的最小 DAMP；没有支持值时交用户判断。

## 物理依据与项目约定

HypoDD 手册第 9、13 页要求检查反演稳定性、结构和簇质心对参数的敏感性。CND 40–80 是经验参考；系统规模、连接和权重也会影响 CND。保留完整日志序列，汇总标明“首个 arnorm > 0.01 的日志记录”；该过滤是项目汇总约定，不作为通过条件，也不代表所有簇。

项目把定性检查实现成以下可复查规则：相邻 DAMP 的去质心结构差异、两次试算的各簇质心位移，均小于实际初始定位 ERH 中位数时，较小 DAMP 获得平台证据。ERH 是项目选择用的空间尺度，不是垂直或三维统计误差界；不能把通过此规则当作深度可信、整体最优或科学质量通过。

## 空间指标

- 原生 `.loc`／`.reloc` 按事件 ID 解析；拒绝重复 ID、非法坐标和未知格式。保留簇编号。
- 比较只用两份目录共同的事件，逐簇计算；记录共同事件数、未保留数、覆盖率和簇明细，避免事件丢失改变比较集合而伪造位移。
- 每簇采用同一个 WGS84 地表切平面计算东、北坐标，单位 km；第三维直接用目录深度 km（向下为正）。该水平投影用于区域目录。经纬度的“度”不参与距离相加。
- **事件位移**：共同事件三维位移的范数，报告中位数。
- **质心漂移**：同一簇共同事件的平均坐标变化；分别报告东西、南北、深度变化、水平范数、垂直绝对值和三维范数。选值使用各簇三维质心漂移的最大值，防止不同簇相反漂移互相抵消。
- **结构差异**：每簇、每份目录先减去自己的共同事件质心，再按 ID 比较三维相对坐标，取位移范数的中位数；选值使用各簇中位差的最大值。包含经度、纬度、深度；簇的整体平移由质心指标单独反映。

## 平台与缺失证据

1. DAMP 必须为有限正数，候选互异且至少两个；按数值升序，只与紧邻的更大候选比较。
2. 两次试算都必须执行成功且有有效目录；任一次失败时不跳过它寻找另一个“合格邻居”。
3. 两次目录涉及的每个簇至少有两个共同事件，才能评估结构；某簇丢失、只有一个共同事件、簇身份改变或文件缺失时不通过。
4. 两次试算各自的最大簇质心漂移，以及共同事件的结构差异，都必须是有限且实际计算出的数值，并低于 ERH 比较尺度。
5. 从获得证据的候选中取最小 DAMP。最后一个候选没有更大邻居时为 `NOT_EVALUATED`，不能把空值当零。
6. 没有候选满足时输出 `NEEDS_REVIEW` 和具体原因。CND、事件数或曲线外观不会覆盖缺失证据。两次结果重合的事件可以稳定，丢失事件仍须单独解释。

## 留档与正式运行

试算分别保存在 `qc/damping_runs_<批次>/damp_<完整数值>/`，包含原生输入、日志、初始与重定位目录。小数候选不会因整数截断共用文件。试算不占用正式 `output/`。

`damping_trials.json` 与 `damping_selection.json` 保存同一组完整指标；选值绑定当前输入、模型、二进制、脚本、档位、ratio 和显式 ERH。正式运行重新核对文件哈希并从留存坐标重算选值，拒绝旧版本、缺失证据、不同配置或不受支持的 `--damp`。

图包含四个面板：CND 经验参考、末条日志加权目录 RMS、事件位移和簇质心漂移、相邻候选结构差异。RMS 的日志作用范围明确标注，不能把来自不同簇或不同保留数据的首末记录相除，冒充全目录残差降幅。
