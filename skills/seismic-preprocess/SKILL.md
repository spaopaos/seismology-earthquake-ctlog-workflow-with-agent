## 0. 任务边界与执行原则

把用户提供的连续波形处理为 **100 Hz、带限地面速度 m/s、Z/N/E 三分量、按 UTC 日归档**的数据。目标分析频带为 **1–40 Hz**；原始采样率不足时按第 3 节缩窄，不因上采样而扩大有效带宽。

用户已经有 Conda、Python、ObsPy、NumPy、SciPy 等科研环境；QC检查现有Matplotlib是否可用，缺失时报告而不安装。只检查现有环境，不安装 Conda，不新建环境，不运行 pip/conda 安装或升级，不修改系统配置；缺失依赖时报告具体问题。优先使用用户指定的解释器或已有环境。

使用本 Skill 的固定规则和初始参数，不进行频带扫描、模型训练或发表级参数优化。用户明确给出的覆盖设置优先，但必须检查合法性并记录变化。这里的预滤波、water level、缓冲和边界余量是本项目的初始处理协议，不是所有仪器与研究任务的统一标准。

优先调用项目已有、与本规范一致的预处理脚本；先读取帮助及实际实现，不能编造命令或假定已有函数。如果没有处理器，可以在本次工作目录编写一个可复用的 ObsPy 脚本，先检查并小批量运行，再处理整批数据。保留实际使用的脚本及配置；不得仅输出处理建议就宣称任务完成。

原始波形、响应文件和已存在的产品保持不变。输出使用独立目录。只处理预处理、归档与本阶段QC，不自行开始 PhaseNet+、GaMMA、定位、震级或机制求解。本阶段不需要区域速度模型，不能因缺少它而阻止预处理。

**交付必须包含真实结果的QC图表与摘要，而不止波形文件。** 索引时即准备全批次统计与代表性快照计划；按第7节及`references/QC_OUTPUTS.md`执行。没有真实数据时只交付规范或脚本，不生成模拟观测图来冒充完成。

## 1. 收集输入；只询问真正缺少的信息

确认以下信息，已在对话或配置中给出的不重复询问：

- 波形文件或目录；支持先检查 ObsPy 能读取的 SAC、MiniSEED 等格式。
- 响应及台站元数据位置；优先使用完整 StationXML。
- 输入物理状态：`raw_counts`，或有明确处理记录和单位的已校正数据。不能仅凭文件扩展名、数量级或存在响应文件就认定是原始计数。
- **输出目录：必须由用户明确指定，不得自行假设或使用默认路径。** 优先级：流水线级配置（`pipeline.json`）> 对话中给出 > 都没有时才询问；前两种情况不重复确认。确认该目录不存在或内容不与本次任务冲突，不覆盖既有产品。
- **计算资源：先检查本机可用资源，再由用户决定用量。** 优先级同上：`pipeline.json` 的 `resources` 段视为一次性授权；对话中给出视为当次授权；都没有时才询问。开工前检查并报告本机 CPU 核数、可用内存和输出盘的剩余空间；配置或对话给定的并行worker数/核数、内存上限不得超出；预估数据量明显超出可用内存时，先向用户说明分批方案。一键批处理模式下，还需核对配置预算与本机实况相符，不符则报错而非静默降级。
- 可选的台站选择和 UTC 时间范围。未限定时间时处理输入实际覆盖的全部日期，不凭空补出无数据日期。
- 指定的现有环境或 Python 解释器；未指定时先检查当前环境。
- **流水线级输入（一键全流程模式）**：区域速度模型（P/S 一对，如 `vel/*.cre`）属于 `pipeline.json` 的 `region` 段，应在流程启动时收集。预处理**不消费**该模型——本阶段不需要区域速度模型，不能因缺少它而阻止预处理；但若配置中已给出，应记录其路径与来源到运行状态，供关联/定位等下游环节取用。模型来源（如 CRUST1.0、区域反演结果）与适用性由用户在配置时声明。

响应必须覆盖实际通道和时间。只有 RESP/PZ 时，先核实对应标识、有效期、单位和完整增益；信息不足的通道暂停，不用一个标量增益冒充完整去响应。元数据需要台网、台站、位置码、通道及方向；台站坐标/高程缺失时保留缺失状态并提示，不能填 0 伪造位置。SAC 的 `-12345` 是未定义值，不是真实坐标或角度。本版只按已确认的地震运动线性响应恢复物理速度；非运动通道或无法确认的响应类型不能因函数返回成功就标为 m/s。

`raw_counts` 执行完整流程。若输入已去响应，先确认单位、频带、方向和历史处理；明确为 m/s 时跳过去响应，且不能再次盲目滤波或声称恢复历史滤掉的频率。历史处理不明确则询问，不自动反卷积第二次。本版的标准计算顺序针对原始计数输入。

## 3. 按原始采样率制定频率方案

### 3.1 确定同一仪器组

使用 `NET.STA.LOC.FAMILY` 区分一组三分量，例如 `XX.AAA.00.HH`。`FAMILY` 为原通道前两位。不同台网、位置码或传感器组合不得只因为台站名相同而合并。存在多套完整仪器时，分别归档，不擅自混选三条通道组成一组。

对于一组仪器，在本次请求的日期范围内，检查三个分量及各采样率时段，取实际有效输入的最低原始采样率 `fs_min`。同一批次内该组采用共同分析频带，避免日期或分量之间出现未说明的频带变化；其他仪器组独立计算，不因一个低采样率台站而降低全网频带。

若用户需要分期采用不同频带，建立独立处理批次或明确的配置分期。模板和扫描后续复用时，应能查到这项差异。

### 3.2 计算规则

```python
nyquist_support = min(fs_min / 2.0, 100.0 / 2.0)
band_low = 1.0
band_high = min(40.0, 0.80 * nyquist_support)
pre_filt = (
    0.01,
    0.02,
    min(45.0, 0.90 * nyquist_support),
    min(48.0, 0.96 * nyquist_support),
)
```

同组使用上述共同频率，各原始分量仍在自己的原始采样率下去响应和滤波。处理前必须逐段检查：

```text
0 < f1 < f2 < band_low < band_high < f3 < f4 < fs_raw / 2
band_high < 100 / 2
```

不满足则不运行该段。0.80、0.90、0.96 是本项目留边比例，不是抗混叠保证或仪器可用带宽证明。响应缺失、单位无法转换或仪器明显不支持目标频带时，不能只凭频率不超过奈奎斯特就判定可用。

| 组内最低原始采样率 | 实际分析带通/Hz | `pre_filt`/Hz | 输出采样率 |
|---:|---|---|---:|
| 200 | 1–40 | `(0.01, 0.02, 45, 48)` | 100 Hz |
| 100 | 1–40 | `(0.01, 0.02, 45, 48)` | 100 Hz |
| 50 | 1–20 | `(0.01, 0.02, 22.5, 24)` | 100 Hz |
| 40 | 1–16 | `(0.01, 0.02, 18, 19.2)` | 100 Hz |
| 20 | 1–8 | `(0.01, 0.02, 9, 9.6)` | 100 Hz |

低采样率组标记 `BAND_LIMITED`，报告原始采样率与实际频带。不说“插值到 100 Hz 后恢复了 40 Hz 信息”。该标记也不代表已经验证了低带宽数据上的 PhaseNet+ 拾取性能。

## 4. 严格执行以下顺序

### A. 检查环境、建立输入索引

读取当前解释器路径及 Python/ObsPy/NumPy/SciPy 版本，检查输入与输出位置。只做导入/版本检查，不修改环境。

先索引文件头，再按台站仪器组和日期读取。至少记录真实 SEED 标识、首末样本时刻、采样率、点数、数据类型、响应匹配及元数据有效期。日期和台站不以文件名为唯一依据。

**读取时显式使用 `obspy.read(..., apply_calib=False)`。** 在输入索引保存原始 `stats.calib`、SAC `scale`、已知单位和既往缩放记录；不知道数据是否已经乘过增益时询问，不能重复乘校准因子，也不能仅以 `calib=1` 认定是原始计数。保留原始首末样本时刻供重采样后的覆盖裁定。

SAC 的采样间隔可能有 float32 舍入。先区分已证实的格式舍入与真实采样率变化；有本项目名义网格或可靠原始元数据支持时，记录这种格式解释，不因此重复插值。没有证据时，不把所有接近 100 Hz 的原始记录强制当作精确 100 Hz。

在正式处理前输出简短方案：台站组数、日期范围、采样率分布、各组实际频带、输出布局和缺项，以及本次计划动用的计算资源（并行worker数、单任务内存上限，须在第 1 节的本机资源检查和用户授权范围内）。材料完整且用户已经授权处理时，不为已约定的每个参数反复请求确认。

同时保存QC请求网格与源数据支持：可用`processing/segment_index.jsonl`记录通道、采样/响应epoch、真实有效区间、源文件与处理去向，覆盖失败和缺分量的组日。依据第7节选择代表组；只保留少量诊断片段，不把所有中间全天波形另存一套。

### B. 整理原始连续段；不要先填零再滤波

按完整通道标识、采样率和响应/方向有效期分组，时间排序；将真正连续的文件片段拼接，不对每个小文件分别去趋势与 taper。

完全重复的数据可以去重并记录。时间重叠且数值冲突时，默认暂停受影响的通道/日期，报告冲突，不直接使用后读文件覆盖、平均或插值。采样率、响应或方向改变处拆段，不跨改变点使用同一响应。

缺口、NaN、Inf、读入的有效性掩码或已知填补区间必须保留为无效区间；按有效连续段处理。不得直接对补齐后的整日零数组执行去响应或滤波，不得用 `data == 0` 推断所有缺口。

**响应按整段唯一匹配。** 在完整 `NET.STA.LOC.CHANNEL` 下枚举候选通道元数据，核查开始、结束及中间所有响应/方向变更时刻，而不只调用一次 `get_response(id, starttime)`。处理段首末样本必须落在同一套确定有效的响应中，波形原始采样率也须与响应所描述的数字采样阶段一致；已证实的文件头舍入单独处理。

同一响应的确证重复条目可以去重并记录；不同响应有效期重叠、方向冲突或边界归属不清时，停止受影响段，不能采用“首个匹配”。传给 `remove_response` 的 `matched_inventory` 必须已消歧到该段所需通道/epoch；不要把含多套候选的完整库直接交给它并忽略警告。元数据缺失只阻止相应段或组，不阻止无关台站。

**短段预检在反卷积之前进行。** 先拼接真正连续的片段；若有效样本不足，或扣除本版两端各 20 s 警戒区后没有可用内部区间，记录 `NO_USABLE_DATA` 并跳过，不为凑长度跨缺口填零。0.01/0.02 Hz 对应的长时间尺度不是“满足某个长度即安全”的定理；对于仍可处理的短段保留警告，首批按第 6 节做代表性检查。不得为了短段静默抬高低频角或改变 water level。

### C. 基础处理 → 去响应 → 分析带通

对每个有效原始连续段使用副本，执行：

```python
import numpy as np

# 前置条件：有效段已拆好，唯一响应已确认，短段预检已通过。
tr = tr.copy()
if np.ma.isMaskedArray(tr.data) and np.ma.getmaskarray(tr.data).any():
    raise ValueError("掩码缺口必须先拆成有效段")
if not np.isfinite(tr.data).all():
    raise ValueError("输入存在尚未拆分的非有限样本")
tr.data = np.asarray(tr.data, dtype="float64").copy()
tr.detrend("demean")
tr.detrend("linear")
tr.taper(max_percentage=0.05, max_length=20.0, type="hann")
tr.remove_response(
    inventory=matched_inventory,
    output="VEL",
    pre_filt=effective_pre_filt,
    water_level=None,             # 或用户明确确认并记录的覆盖值
    zero_mean=False,
    taper=False,
)
if not np.isfinite(tr.data).all():
    raise ValueError("去响应后出现非有限值，停止本段，不填零掩盖")
# 仅在完整响应及单位已经确认、数组确已转换为 m/s 后执行。
# 原 calib/scale 与响应信息须先存入外部记录；此处不改变数组振幅。
tr.stats.calib = 1.0
tr.filter(
    "bandpass", freqmin=1.0, freqmax=effective_band_high,
    corners=4, zerophase=True,
)
if not np.isfinite(tr.data).all():
    raise ValueError("带通后出现非有限值，停止本段")
```

这是单段运算顺序示例，不是完整日处理器；其中响应匹配和有效参数必须来自前面检查。读取完整计数→物理量响应，不重复乘/除灵敏度。不能先 `remove_sensitivity()`，再把其输出当计数执行完整 `remove_response()`。只有 RESP/PZ 时须先有明确单位与增益的已核实适配路径；没有时报告，不拼凑缺失响应。

捕获并记录响应错误、灵敏度不一致和数值警告；多响应冲突、无法转换的单位及非有限结果不能放行。`water_level=None` 不代表没有噪声放大风险；显著异常按诊断处理，不做自动裁剪、`nan_to_num` 或更改参数来伪装成功。导出时不把原始 `stats.response` 附在已校正派生数据上供下游误用，原响应来源保存在元数据中。

对历史上已确认为 m/s 的输入，也须先保存原 `calib/scale` 并核实数组已经包含哪些变换，再将派生头统一为 1；不能借此解决未知历史增益或单位。

不用归一化、白化、AGC、one-bit、取绝对值或人为振幅裁剪。不要为了震相拾取归一化而覆盖该物理量归档；模型内部需要的归一化留给后续临时输入副本。

对QC抽样计划选中的实际处理段，在去响应前、去响应后未分析带通、带通/重采样/对齐后旋转前，以及最终ZNE阶段截存必要的短片段与真实时间/单位/轴方向。必须从本次长段计算中截取，不能另对短窗重新去响应冒充原流程中间量。见`references/QC_OUTPUTS.md`。

### D. 真正重采样，并对齐同一 UTC 网格

去响应和带通完成后，再将非 100 Hz 连续段转换至 100 Hz。优先使用 `resample_poly` 的有理数采样率转换，显式设置 `window=("kaiser", 5.0), padtype="constant", cval=0.0` 并保留抗混叠 FIR；常见 200→100、50→100、40→100 分别是 1/2、2/1、5/2。

重采样滤波器在有限段边界使用的数值填充不属于实测数据，不扩大有效区间；仍保留边界警戒区。原始采样率已为 100 Hz 且采样点对齐时，不重复重采样。不得只写 `tr.stats.sampling_rate = 100`；不得直接隔点抽取。

所有输出落在目标日 `D + k/100` 的网格上。若开始时间有亚采样偏移，用实际插值校正采样位置，不能通过改 `starttime` 把样本强行对齐。可使用已有、经过检查的对齐函数；没有时采用 ObsPy Lanczos 插值（显式 `method="lanczos", a=20`）对齐重采样后的有效段。只在已有数据覆盖范围内取样，不外推，也不跨缺口插值。

**覆盖由原始有效样本决定，不由重采样返回的数组长度决定。** 每个有效段记录原始第一、最后样本时间 `t0_raw`、`tlast_raw`（均含该样本）；重采样后的目标样本仅在这两个时刻之间取用。对于目标日 `D`，未计边界警戒前的支持索引为：

```text
i0 = max(0, ceil((t0_raw - D) * 100))
i1 = min(8_640_000, floor((tlast_raw - D) * 100) + 1)
实际支持为 [i0, i1)，再与处理结果覆盖相交，并扣除边界警戒。
```

按相对时间、整数采样索引或高精度时间实现；只容许经过记录的浮点舍入，不能用半个样本的容差把真实覆盖向外扩大。若 `i1 <= i0`，该段不提供当天可用样本。需要处理相位偏移时仍执行真实插值，不以改头代替。

例如 40 Hz 的 40 点从 0.000 至 0.975 s，`resample_poly(..., 5, 2)` 返回 100 点至 0.990 s；按本版保守覆盖约定，只接受 0.000 至 0.970 s 的 98 个目标网格点，0.980/0.990 s 不能计为新观测。后续归档再按缺口补零。这里限制的是输出的观测支持，不声称滤波/插值完全不受段外边界填充影响。

每次重采样/插值后检查有限值。记录转换比例、原始首末样本、裁掉的边界合成点数、实际时间偏移和有效区间。特殊非整数采样率无法按实现可靠转换时，报告而不是近似修改时间头。

### E. 三分量整理为 Z/N/E

先对每个原生分量使用自己的响应得到物理速度，再考虑分量旋转。禁止先将原始计数旋转，再给三个旋转分量共用一份原始响应。

已由元数据确认方向为 Z/N/E 的数据保留对应方向。Z/1/2 或其他方向必须依据实际 azimuth/dip（或可信 SAC 方向头）使用 `rotate2zne`/`rotate("->ZNE")` 转换；不能直接把 1 政名 N、2 政名 E。输出 Z 正向为向上，N 向北，E 向东；通道名本身不是方向已验证的证据。

**角度约定必须先转换：** StationXML/SEED 的 `dip` 从水平向下计量，SAC `cmpinc` 从向上竖直方向计量。因此 `dip = cmpinc - 90.0`；方位角采用从北顺时针的 `cmpaz`。缺失、`-12345`、越界或相互冲突的角度不能当作 0。明确来源后使用实际方向，不把“近似水平/竖直”静默改成理想值。

| 输出轴 | azimuth / deg | SEED dip / deg | SAC cmpaz / deg | SAC cmpinc / deg |
|---|---:|---:|---:|---:|
| Z（向上） | 0 | -90 | 0 | 0 |
| N（向北） | 0 | 0 | 0 | 90 |
| E（向东） | 90 | 0 | 90 | 90 |

Z 轴的方位角 0 为竖直轴的表示约定。原轴向下或朝南等情况下，应按实际基变换处理符号，不能用取绝对值修正。旋转后重写上述输出方向头，不继承旧 `cmpinc/cmpaz`。新方向表不会证明原始传感器方向无误，源方向与依据仍须保存。

需要一般三轴旋转时，仅在三条速度记录共同有效、时间一致的区间旋转；不把某轴补零后仍称其为完整旋转结果。元数据不足或方向矩阵不可用时，暂停该组并报告。原生已是 Z/N/E 时，可分别保留各分量真实有效数据，同时计算三分量共同可用区间。

旋转后立即检查有限值，并将参与旋转各轴的可用区间交集作为对应输出的可用区间；不能只保存覆盖交集而丢掉边界警戒。保存原通道标识、方向来源、转换公式、实际旋转及符号变化、响应与输出分量的对应。不能混合不同传感器的三条轴，也不自动旋转成径向/切向。

### F. 必须显式合并补零，再切日与归档：`merge(fill_value=0)`

默认按目标日前后各 60 s 的真实缓冲读取和处理，完成后只截取目标 UTC 日。跨日仍连续且元数据不变的数据，不把午夜当成人为缺口；缓冲缺失时只使用真实数据，并标记边缘。

一个普通 UTC 归档日定义为半开区间 `[D, D+1日)`：

```text
starttime = D 00:00:00.000 UTC
sampling_rate = 100.0 Hz
npts = 8,640,000 / 分量
最后一个样本时间 = D 23:59:59.990 UTC
```

不要包含次日 00:00:00 样本。使用 ObsPy `trim` 时，上端应按最后一个样本处理，或直接按整数样本索引裁切；不能以闭区间两端都包含的方式得到 8,640,001 点。

**必须对每个输出通道显式执行 `Stream.merge(method=0, fill_value=0)`，不能仅在报告中写“已补零”，也不以手写零数组装配替代本版约定的 merge 调用。** 这里合并的是同一个 `NET.STA.LOC.CHANNEL` 的多个时间片段；Z、N、E 分别合并，不是将三个分量相加。

执行条件：去响应、分析滤波、100 Hz 重采样、真实时间对齐以及必要的旋转均已完成；同通道片段的单位、频带、采样率和数据类型一致，且已在确认物理量后将派生 `stats.calib` 统一为 1.0。先记录数据覆盖和缺口，再检查重复与重叠。完全相同的重复样本可去重；任何数值冲突必须按第 B 步暂停并报告，不能依赖 `method=0` 把冲突样本填成零来隐藏问题，也不能改用 `method=1` 静默覆盖。

下面是**一个已有数据的单通道**的最终装配示例，不是完整预处理器。`component_stream` 只包含该通道、与目标 UTC 日有真实交集的已处理片段，`day_start` 为目标日的 `UTCDateTime` 午夜；二者及缺口元数据来自前序步骤。

```python
import numpy as np

# 前置条件：片段均已处理并对齐到 day_start + k / 100 的公共网格；
# 已检查且不存在数值冲突的重叠，已独立保存真实覆盖和缺口区间。
component_stream = component_stream.copy()
if not component_stream:
    raise ValueError("缺少该分量，不得生成全天全零文件冒充观测")
if len({tr.id for tr in component_stream}) != 1:
    raise ValueError("一次只能合并同一完整通道标识的片段")
for tr in component_stream:
    if abs(tr.stats.sampling_rate - 100.0) > 1e-8:
        raise ValueError("合并前必须完成真实重采样到 100 Hz")
    if tr.stats.calib != 1.0:
        raise ValueError("派生 calib 未统一；返回单位/响应步骤核查，不在此强制改头")
    if np.ma.isMaskedArray(tr.data) and np.ma.getmaskarray(tr.data).any():
        raise ValueError("合并前仍有未处理的掩码")
    if not np.isfinite(tr.data).all():
        raise ValueError("合并前存在非有限值")
    tr.data = np.asarray(tr.data, dtype="float64")

component_stream.sort(keys=["starttime", "endtime"])
component_stream.merge(method=0, fill_value=0)  # 必须显式执行：内部缺口补零
if len(component_stream) != 1:
    raise ValueError("单通道合并后未得到一条记录")

day_trace = component_stream[0]
last_sample = day_start + 86400 - 1.0 / 100.0
day_trace.trim(
    starttime=day_start,
    endtime=last_sample,
    pad=True,
    fill_value=0,             # 日首尾没有观测的部分补零
    nearest_sample=True,     # 此前已完成真实网格对齐，不用裁切伪造对齐
)
if day_trace.stats.npts != 8_640_000:
    raise ValueError("UTC 日样本数错误")
if abs(day_trace.stats.starttime - day_start) > 1e-6:
    raise ValueError("日文件起始时间未对齐")
if abs(day_trace.stats.endtime - last_sample) > 1e-6:
    raise ValueError("日文件末样本时间错误")
day_trace.data = day_trace.data.astype("float32")
if not np.isfinite(day_trace.data).all():
    raise ValueError("float32 保存前出现溢出/非有限值；不得写为成功产品")
```

`merge(fill_value=0)` 填充片段之间的缺口；`trim(pad=True, fill_value=0)` 补齐当日首尾。两步都需落实，且均发生在信号处理之后。合并和补齐以后不再对整条含人工零段的日记录执行去响应或滤波。

处理记录须保存实际合并方法、填充值、日首尾补齐设置及填补样本数；`gap_fill_value`、merge 的填充值和日首尾填充值必须一致为 0。有效区间仍来自真实片段的覆盖记录，不从补齐后的振幅值推断。

保存每个分量实际有数据的区间，以及排除边界警戒区后的可用区间。20 s 警戒区按实际连续处理段边界计算，投影到目标日；有真实缓冲时不要再人为屏蔽整日两端。短段若没有剩余可用区间，则不进入下游可用列表。

只保留半天或存在缺口时仍可输出整日文件，但必须记录 `PARTIAL_DAY`，不能说有 24 小时观测。整天缺一个分量、无法形成三分量，或三分量没有共同可用区间时，不生成看似完整的三分量组；在清单中记录原因。原始数据不删除。

本版按 ObsPy 的普通 86,400 s 日网格处理；遇到显式闰秒样本或冲突时标时，单独报告该日，不静默丢弃或重复样本。

### SAC 头与单位规则

从处理后的记录建立干净的连续数据头，写入实际 NET/STA/LOC/输出分量、时间与可核实的台站坐标、高程和方向；不继承过期的事件坐标、震相时间和原始响应标记。使用 SAC 的 `b=0` 和当前 UTC 午夜参考；`e` 根据点数和采样间隔生成，不能抄原头。方向按第 E 步重写。

**派生校准约定：`stats.calib=1.0`，SAC `scale=1.0`。** 明确写入两个字段，不假定写入器总会用 Stats 覆盖旧 SAC 头。原 `calib/scale`、是否曾应用以及对应响应保留在元数据。回读时 `apply_calib=False`，同时检查数组数值和校准字段；字段设为 1 不是一次新的振幅缩放。

数据数组保持 **m/s**。设置 `kuser0="VEL_M_S"`，并在 `metadata.json` 写 `units="m/s"`、`response_removed=true`。SAC 的 `IVEL` 枚举按规范表示 nm/s；因此本版不把 m/s 数据冒充该单位，`idep` 使用 `IUNKN`，并明确要求下游从本项目元数据读取物理量。不得额外乘 10^9，亦不得因 `idep` 非 IVEL 再次去响应。

SAC 的 float32 头无法逐位精确表示 0.01；回读允许该格式的舍入：`|delta-0.01| <= 1e-8 s`，最终时间与名义日网格偏差不超过 0.005 s，点数仍必须精确为 8,640,000。元数据保存精确名义采样率和日网格。SAC 中可能存在的正常头舍入不等于允许修改原始记录时标。对本归档的正常舍入，不再次重采样；对真实的原始频率/时钟差异，不用这项容差免责。

### 每日元数据与总清单

每组每日的 `metadata.json` 至少包含：

- 台站组、UTC 日、原通道与输出通道、旋转方式、真实方向信息及来源、SAC↔SEED角度约定、输出方向头；
- 原始采样率集合、目标采样率、分析频带、`pre_filt`、water level、处理顺序；
- 输入与响应文件、各原始段首末样本、响应有效期与唯一匹配结果、原 calib/scale 及已知应用历史、派生 calib/scale、实际处理脚本/版本；
- 三条输出文件名、`physical_quantity="ground_velocity"`、`units="m/s"`、`processing_state="response_corrected_band_limited"`、起点、名义终点（不含）、点数；
- 各分量 `data_intervals`、`usable_intervals`，及 `usable_3c_intervals`；
- 合并记录：`merge_method=0`、`merge_fill_value=0`、`day_pad_fill_value=0`、缺口及日首尾填补样本数；
- 缺口、边界标记、重采样裁除的合成边界点数、覆盖率、状态和警告；处理阶段有限值检查及首批诊断是否实际完成。

所有区间采用日网格整数索引 `[i0, i1)`，取值范围 0 到 8,640,000；由读取和处理记录计算，不能从波形值是否为 0 反推。`data_intervals` 表示有实际输入支持的处理后样本，不表示科学真值；`usable_intervals` 另排除已标记边界。共同区间为三分量可用区间的交集。

`daily_manifest.csv` 每个仪器组每天一行，至少含：组标识、日期、状态、原始采样率、实际频带、三条输出路径、元数据路径、三分量共同可用比例、失败/警告原因。路径相对 `<output_root>`；未生成文件时留空，不填写不存在的路径。

写入先使用临时文件，回读通过后发布该日产品。已有同名输出不能盲目跳过或覆盖：输入和配置确实一致且回读通过才复用，否则使用新输出目录或询问。

## 6. 基础检查与成功判据

先对一组实际台站日进行小规模运行，确认处理顺序、单位、频率、分量、显式 `merge(fill_value=0)`、日首尾补齐、日网格与归档正确，再批量执行；这不是参数优化。存在多种原始采样率时，各类至少检查一次频率方案。测试失败不继续扩大任务。

同一项目首次接入一种明显不同的仪器响应类型时，保存一段代表性数据的去响应频域诊断及午夜/缺口附近波形；无需每站每天画图，也不要求测试最优频带。诊断在单独副本上进行，不把已经去响应的数据再次反卷积。60 s 缓冲与 20 s 警戒仍是初始策略，不能称为已证明消除 0.01 Hz 预滤波或 IIR 全部边界影响；发现异常时记录并阻止相应数据进入可用列表，调整参数需有明确依据。

去响应、滤波、重采样、旋转后以及 float32 转换后都检查有限值；真实输入的 NaN/Inf 可以先作为缺口拆段，处理过程产生的 NaN/Inf 则是本段失败，不能变成普通缺口掩盖数值错误。具体运行前检查表见 `references/IMPLEMENTATION_CHECKLIST.md`。

每个已发布日产品回读检查：三分量与实际仪器组对应；采样率符合目标及格式容差；日期、点数、末样本正确；数据有限且无整条恒定/全零的假分量；`calib/scale=1.0`、方向头与单位正确；元数据与有效区间一致；有效区间不超出原始支持；内部缺口与日首尾应填区域的数值确实为 0，补零位置没有被算作有效观测。

异常大振幅、疑似饱和等先报告，不通过裁剪数据掩盖问题。频带降级、零填充、边缘影响和响应警告必须保留。不要以平均值必须严格为零作为完成判据，因后续滤波和裁切可能改变均值。

**QC 必须包含物理真值断言，不能只查格式一致性。** 至少：逐日振幅量级合理性（本区域连续波形速度振幅明显超过 cm/s 量级须告警；INC-001 中 1.8e18 m/s 即由此类断言暴露）、同一天重跑逐位一致（缓存/加速优化的回归自检）。库函数可能原地修改传入数组（ObsPy `remove_response` 先例），任何缓存按副本返回。

总清单需对所有请求的仪器组/日期交代去向。状态建议使用：`READY`、`PARTIAL_DAY`、`NO_USABLE_DATA`、`INCOMPLETE_COMPONENTS`、`BLOCKED_METADATA`、`FAILED`；频带受限作为单独警告 `BAND_LIMITED`。`READY` 只表示通过本流程基本检查，不表示拾取或定位精度已经验证。

单个站日失败时隔离并继续不受影响任务，除非发现是公共脚本或公共配置错误。不能把跳过算成功；没有实际成功产品时，明确说没有生成可用三分量归档。

## 7. 结果可视化与QC交付（必须执行）

完成归档回读后，根据真实输入索引、有效区间、处理记录和产物生成下列QC。完整字段、抽样及失败处理见`references/QC_OUTPUTS.md`；配置见`assets/preprocess.example.json`的`quality_control`。仅更新规范时不要生成假数据质检图。

### 7.1 必需图表

| 输出 | 默认文件 | 内容 |
|---|---|---|
| 逐台站组逐日可用性 | `qc/availability_heatmap.png` | 三分量共同可用覆盖0–100%；缺响应、缺分量、未计算、无输入等用独立状态，不以空值冒充0 |
| 台站分布 | `qc/station_map.png` | 可信坐标及处理状态；缺坐标名单单列，不填0、不强制在线底图 |
| 原始采样率 | `qc/sampling_rate_hist.png` | 去重的通道采样epoch数量；不是输出100 Hz的统计，也不是输入碎文件数量 |
| 三分量完整性 | `qc/component_completeness.png` | 原始各轴出现情况、是否有共同时间及是否生成输出，保留失败组日 |
| 缺口汇总 | `qc/gap_statistics.png` | 根据真实覆盖统计；输入缺测、输出支持裁除、边界剔除和日首尾填零分开 |
| 实际频带 | `qc/effective_band_summary.png` | 真正已发布组日采用的频带；候选设置不算实际使用 |
| 抽样波形 | `qc/waveform_examples/` | 原始、去响应后及最终数据，同一窗口、明确单位与轴；异常/午夜/缺口例有则保留 |
| 抽样PSD与响应诊断 | `qc/spectrum_examples/`、`qc/response_examples/` | 实际有效片段及真实响应的诊断；不能重复去响应或将补零整日当连续观测 |
| 表与报告 | `qc/*.csv`、`qc/qc_summary.json`、`qc/qc_summary.md` | 包含归档回读、响应状态、抽样来源、缺项及所有图件路径 |

总览默认静态PNG、160 dpi，每张独立成图；热图超过50组/90日分页，不能隐藏剩余记录。表保存全量，不要求逐组每日画完整波形。绘图依据实际数组/元数据，不调用图像生成工具，不安装新库或下载底图。Matplotlib不可用时保存能生成的统计并报告QC不完整。

### 7.2 统计口径

台站数、仪器组数、通道数与组日数分别报告。覆盖从处理前索引和后续有效区间计算，不根据文件个数、整日SAC头或振幅是否为0估计。

每日Z/N/E可用区间的交集才是三分量共同可用区间，不能取三个比例的均值或最小值。整日比例以8,640,000点为分母；仅请求部分日期时另算请求内比例，保留请求外说明。中途全部缺测的日期在QC中可见，不为此创建假波形。已有部署期则区别部署外和缺测，不从无文件推断未部署。

输入已知缺测可以为0；因处理失败而没有派生产物的对应覆盖用null和原因表示。可另报实际交付的3C可用时长，缺产品时为0，但不能将其冒充已计算的输出覆盖。所有失败、缺响应、缺轴单元都必须出现在表与总览状态中。

### 7.3 抽样与视觉检查

默认按原始采样率、仪器响应类型和旋转需要选择最多6个基线组，另选最多3个实际异常例；固定选择顺序，保存理由、组、UTC时窗和实际配置。未覆盖类别明确列出，不制造事件或异常。波形默认120 s，PSD优先600 s连续有效窗；没有足够数据就报告真实长度或未生成原因。

原始计数与m/s不同单位分开绘图；原轴1/2不能当成旋转后的N/E直接比较。中间量必须来自实际处理阶段的快照。缺口保留可视标记，PSD只使用不跨缺口的连续有效样本；不对补零整日直接估计PSD。Welch默认10 s窗、50%重叠、Hann、density，具体代码与单位见QC说明。

图表生成后必须实际检查：文件存在、可打开、单位/日期/标题正确、失败组没有消失、图与CSV/JSON一致。Agent有图像工具时打开总览及生成的抽样图，写入`qc/visual_review.json`；不能查看时保留NOT_REVIEWED并告知用户，不只检查PNG字节数就声称看过。

### 7.4 完成判据与交付

至少生成`station_summary.csv`、`availability.csv`、`sampling_rate_epochs.csv`、`component_completeness.csv`、`gap_statistics.csv`、`effective_band_summary.csv`、`response_status.csv`、`archive_integrity.csv`和`sample_selection.csv`。列定义见`assets/qc_table_columns.json`；没有相应行可保留表头并说明，未知值不伪填。

`qc_artifacts.json`记录每项输出的GENERATED/NOT_APPLICABLE/BLOCKED_INPUT/FAILED及实际路径；整体`qc_generation_status`为NOT_RUN/COMPLETE/PARTIAL/FAILED。COMPLETE只说明适用QC交付齐备，不表示所有台站或科学结果良好。有效图表因数据/依赖不足未生成时为PARTIAL；不可用项目不能伪装成示意图。

`qc_summary.json`和`qc_summary.md`由实际表生成，列明真实完成状态、覆盖、频带、失败与主要警告、抽样范围、图件入口、待人工查看内容。模板见`assets/qc_summary.example.json`与`assets/qc_report.template.md`，必须以实际结果替换占位，未执行的检查不改为通过。

归档有效但QC不全时报告“波形已处理，QC交付不完整”，不删除或重新滤波已检查的波形。QC可重新生成而不重跑科学处理；但缺少中间快照时不得伪造。模型输入验证状态仍独立保留，QC完成不自动等于PhaseNet+输入已验证。

## 8. 向下游交接，防止重复处理

本归档是**带限速度**，不是原始计数、加速度或未滤波宽频波形。后续读取器必须关闭重复应用 `calib/scale`、去灵敏度、去响应、不必要的再次滤波，以及对已为速度的数据再次执行“加速度→速度”积分。模型要求的临时归一化与单位转换不是一回事，不能覆盖归档。

**尤其检查 HN/BN/EN 等强震来源通道。** 2026-09-10 核查的 EQNet `read_mseed()` 有按通道家族末位 `N` 触发积分和高通的路径；不能假定其读取本项目的 `metadata.json`。本地版本须检查实际代码：已为 m/s 的派生数据不得进入这种再次积分路径。若无受支持的关闭方式，使用经过检查的读取适配器/中间表示；不通过把 HN 偷改为 HH 欺骗读取器，也不擅自修改用户全局安装的 EQNet。该风险不意味着所有版本都有相同实现。

**SAC 是本版归档格式，不是对所有模型入口的即插即用承诺。** 后续接入时确认锁定版本能读取的格式、三分量顺序、数值缩放和时间轴。需要转换为 MiniSEED/HDF5 或数组时，保存原通道映射、物理单位、有效区间和时间信息；MiniSEED 波形文件不能被默认认为保存了本项目所有附属字段。读取器若不消费旁置元数据，就由适配器消费。具体核对路线见 `references/DOWNSTREAM_HANDOFF.md`；本 Skill 不启动模型或自动安装转换依赖。

向输出根目录写 `downstream_contract.json`，从实际配置和产品生成，不原样拷贝空模板。至少声明：`physical_quantity="ground_velocity"`、`units="m/s"`、`response_removed=true`、已完成带通/100 Hz转换、归档组件Z/N/E、禁止重复校正/积分、有效区间来源和参考manifest。模板见 `assets/downstream_contract.example.json`。

`archive_validation_status` 与 `model_input_verification.status` 分开：归档可通过检查，但在实际下游读取路径没有测试前，模型接入保持 `NOT_TESTED`，不得声称拾取输入已经验证。以后接入时，用已知速度数组（包括强震来源标识）检查模型归一化前的读入数组，确认没有额外缩放、积分、换轴或改时；报告实际读入器版本与处理步骤。

下游按真实组件映射重排至所用权重的输入顺序，不能假定文件排序就是网络顺序。`data_intervals`/`usable_intervals`/`usable_3c_intervals` 必须被实际用于切窗、拾取、极性和振幅筛选；补零点及边界警戒区不能成为直接接受的观测。对跨缺口窗口按明确策略切分、拒绝或保留无效标记，不能跨缺口插值、仅凭预测概率放行或默认丢弃整个站日。

供 MESS 使用时，模板与扫描必须采用兼容的处理设置；若后续要求不同采样率或频带，生成单独派生副本，按真实有效区间处理，不改本归档、不冒充新增频率信息。

## 9. 最终向用户报告

报告实际输出目录、处理的站日数、成功/部分/失败数、原始采样率及频带收缩情况、三分量有效覆盖和主要未解决问题。给出清单、配置、下游读取约定、示例产品以及`qc/qc_summary.md`、总览图的真实路径，并说明图是否实际审阅。QC未完成则直述缺项。分清“预处理归档已完成”与“PhaseNet+ 输入尚未验证”；某种检查没实际运行，就保留未运行状态。

不要声称自动寻得最佳频带、修复了未知仪器响应、补回了缺失波形或已经验证后续模型精度。尚未运行、尚未回读或仅编写了脚本时，明确说明真实状态。

实现相关 API 的依据与本项目默认的区别见 `references/TECHNICAL_NOTES.md`；使用前按本机安装版本核对有差异的接口。配置示例见 `assets/preprocess.example.json`，它不是某个已安装 CLI 的参数签名。
