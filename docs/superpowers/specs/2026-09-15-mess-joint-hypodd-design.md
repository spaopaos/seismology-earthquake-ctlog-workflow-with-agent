# MESS 后的 CC + CT 联合 HypoDD 工作流设计

日期：2026-09-15。状态：用户已明确采用独立 CT，并修正为仅三套目录；据此实施。

## 用户要求与范围

将标准执行顺序更新为：预处理 → PhaseNet+ → GaMMA → HYPOINVERSE → 第一轮 HypoDD（CT）→ MESS → 第二轮 HypoDD（CC + CT）。第二轮必须实际使用两种差分走时，参数试验遵循现有 HypoDD 空间证据规则。

本次交付对象是可执行工作流、配置、技能说明、契约和验证。现有地区数据可用于新目录内的验收，不能把工作流代码修改等同于该地区第二轮科学计算已经完成。现有地区运行、原生输出和验证记录保持原有身份。

复用 runtime.local.json。2026-09-15 的 doctor 检查已通过现有三个解释器、钉版二进制、源码身份、权重和知识快照检查；不创建或升级环境。当前目录没有 Git 元数据，不初始化 Git，也不声称已经提交代码。

## 方案比较与推荐

| 方案 | 实现方式 | 取舍 |
| --- | --- | --- |
| 新增 post_detection_relocation 阶段（推荐） | MESS 后增加独立入口，复用原有空间指标和选值规则，支持 CC + CT 输入 | 阶段顺序明确，分别保存两轮定位及其证据，便于独立恢复和验收 |
| 在 relocation 内增加前后两种运行模式 | 同一阶段根据上游类型切换 | 名称较少，但阶段顺序、缓存标识和状态记录更易混淆 |

## 产品组织

MESS 保留一套模板库、一次扫描/关联及三个 CC 门槛目录。第二轮分别消费 cc_0p4、cc_0p6、cc_0p8，只形成三份独立正式目录。每个目录自行试算并选择 DAMP；默认共享初轮中档的配对参数，联合权重单独显式设置。不生成九套正式目录，不跨 CC 档合并。

每个 CC 档保持原始 event_id 和 known/new、known_match_method 等检测信息；需要的模板参考事件单独标明角色，不计入新增检测数。重新定位后的坐标单独输出，保留模板初始坐标供对照。共同事件在不同求解中可能得到不同位置，不能要求求解后坐标一致。

目录：post_detection_relocation/cc_0p4/，其余两个门槛同构。各自 qc/ 下保存 DAMP 试算。分别发布原生 loc/reloc/res、标准目录、事件保留/排除映射、输入来源、试算和正式运行记录、QC、契约以及顶层索引。

## CC 与 CT 来源

CC 使用已经完成关联并通过检测契约校验的 MESS dt.cc，保留原始测量、权重和参考模板引用。维护转换器完成格式和基准适配，不能修改钉版 PALM 源码来适配一次分析。

CT 来源已经由用户明确选定：

- 复用独立 PhaseNet+ 到时，按事件、完整台站身份及 P/S 相位匹配到检测事件，交给 ph2dt 生成 dt.ct。保留原始拾取索引、概率、匹配偏差与排除原因；有歧义的匹配不强行归属，缺测不填充为模板理论到时。
- 不使用 MESS phase.csv 的到时作为 CT 数值。MESS 相位只用于匹配窗口定位，不能冒充独立到时。

匹配窗口和排除规则在维护配置中显式表达，保留匹配诊断。模板参考事件可使用有原始身份依据的上游关联拾取。单个事件缺少 CT 时可以通过 CC 连接参与联合事件集，但须报告该事件实际约束来源。

禁止将 dt.cc 改名或数值复制后伪装成 dt.ct。正式联合求解要求实际存在有效 CC 和有效 CT；任一类缺失均报告受影响档位不可用，不能静默退化为单一数据类型。另行保留无可定位事件的真实空结果。

## 输入基准与检查

1. 建立每个 CC 档及其必要参考事件的统一事件表。模板自检测沿用原 ID；时间窗匹配不自动合并成同一事件。
2. CC 与 CT 采用同一套实际求解发震时间。检查 CC 的事件顺序、DT=T1−T2、OTC 与时间取整；必要适配必须可重算，并保留原文件。用已知时间扰动的测试证明修正方向。
3. 台站采用可逆别名映射，保留网络和仪器组来源。MESS 裸台站名必须能唯一回到完整身份；重名歧义必须拒绝。
4. 核查检测记录的 hypodd_depth_offset_km。新阶段将输入恢复到声明的海平面深度基准并与同基准速度模型一起求解，不能只给事件加偏移、求解后再减去而忽略模型坐标。负深度或当前二进制不支持的情况记录并停止受影响输入，不能凭空抬深。
5. ph2dt 使用统一事件表和 CT 相位；其筛选输出不能意外删除 CC 引用的参考事件。独立验证最终 event.dat、dt.cc、dt.ct、station.dat 的全部引用、重复观测、单位、有限数值和权重范围。
6. 从实际原生日志和结果核对两类数据的读取/使用计数；输入文件非空不等于两类数据实际参与求解。

## 参数试算

沿用 skills/seismic-relocation/references/damping.md 的空间证据规则及实现：

- 明确声明有限正数、互异且至少两个 DAMP 候选，先参考既有 20/50/100/200 候选；需要更大相邻候选时在新试验配置/目录中扩展。第一轮已有支持的 DAMP 不自动成为第二轮最优值。
- 相邻候选仅按紧邻的更大值比较；逐簇、逐共同事件检查去质心三维结构差异、两次解各自的质心漂移、保留数和覆盖率。
- 从有当前证据支持的候选中采用最小 DAMP。最后一项缺少更大邻居、簇身份改变、共同事件不足、文件缺失或求解失败均不能自动通过。
- CND 40–80 仅作经验参考，不用作通过/拒绝门槛。
- ERH 比较尺度必须注明来源。MESS 继承的位置没有新增事件自己的实测 ERH；若参考本地区上游定位的 ERH 中位数，明确它只是沿用的比较尺度，不能写成新事件定位误差。
- 继续检查当前地区 Vp/Vs 的来源和适用性，记录使用相同模型/比值的理由。

联合输入需要明确配置 WTCCP/WTCCS、WTCTP/WTCTS、WRCC/WRCT、WDCC/WDCT、OBSCC/OBSCT；不能仅把 IDAT 改为 3 却继续关闭 CC 权重。参考手册的分阶段加权思路：较大尺度先由 CT 约束，后续增强近距离 CC 约束，所有数值作为显式初始工作设置、经当前数据检查后使用，不宣称适用于所有地区。

手册指出 IDAT=3 下 OBSCC 与 OBSCT 的和用于聚类门槛；因此不能简单将原来的 3/4/6 分别赋给两者后仍声称沿用同一门槛。实现时核对钉版二进制的实际行为并记录有效门槛。WRCC/WRCT 大于等于 1 表示标准差倍数，0 到 1 为秒，−9 表示关闭剔除；WDCC/WDCT 单位为 km。

试算证据绑定两类差分时、初始事件表、台站、模型、比值、迭代表、聚类设置、脚本和二进制身份。正式运行重新验证文件与空间指标。变动后必须重做相应试算。

## 验证与验收

必须验证实际行为，不以生成配置文件或成功退出代替联合重定位：

1. 单元/回归检查：CC 符号、发震时间修正、秒跨界和时间精度；台站重名；事件/参考引用；深度基准；CT 来源及歧义；跨档 ID 保持。
2. 门禁检查：缺 CC、缺 CT、非法权重、缺参考事件、输入篡改、旧 DAMP 证据、失败邻居、单事件簇、无更大候选等均不能伪装为成功联合求解。
3. 使用钉版 ph2dt 和 HypoDD 的小型可控联合数据测试，确认 IDAT=3 实际消费 CC 和 CT，并对已知相对位置/时间扰动作检查；同时回归原来的 CT 路径。
4. 三个结果位置均有明确状态；失败不写零事件冒充空目录；三 CC 档不合并；实际输出保留原始检测 ID。
5. 报告两类残差及其样本/簇范围、保留率、空间变化和限制。日志最后一项 RMS 不冒充全目录统计，DAMP 稳定不等于地质位置已确认。
6. 完成知识身份、契约、原有回归检查。现有 knowledge 测试会无差别复制整个包；执行前应将测试副本限定到所需文件，避免把本机 test_raw 和 runtime 一并复制。
7. 明确区分工作流测试完成与这批地区数据的第二轮运行完成；实测结果只在新运行目录中产生并报告。
